# Solvra

## Solar-Powered Wireless EV Charging

Solvra is a concept for a solar-powered wireless EV charging system designed to make EV charging more convenient and sustainable.

### Project Concept

Solar Panels → Battery Storage → Wireless Charging System → Electric Vehicle
